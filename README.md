# Laboratory Assignment 1: Conditional Statements and Decision-Making in Python

This repository contains the Python programs developed for Laboratory Assignment 1 as part of the **Introduction to Python Programming** course at **Karabakh University**.

##  Repository Overview
The project focuses on using conditional statements (`if`, `elif`, `else`), logical operators, and basic user input handling to solve decision-making problems.

##  Project Structure
* `BMICALCULATOR.py` — Program that calculates Body Mass Index (BMI) and determines the weight category.
* `CHINESEZODIACCALC.py` — Program that determines the Chinese Zodiac animal sign based on the user's birth year.
* `BIRTHDAYGUESSINGGAME.py` — Interactive game that calculates the user's birthday using predefined sets of numbers.
* `README.md` — Project documentation.

##  How to Run
Run any of the Python files using a Python 3 environment:

```bash
python BMICALCULATOR.py
python CHINESEZODIACCALC.py
python BIRTHDAYGUESSINGGAME.py
